# Bot de Atendimento — Condomínio Vista de Pitanga

Projeto pessoal desenvolvido por Guilherme Henrique Peterlini Tavares.

## Visão Geral

Bot de atendimento automatizado construído com TypeBot para o Condomínio Vista de Pitanga.

## Estrutura do Repositório

| Arquivo | Descrição |
|---|---|
| `typebot-vista-pitanga.json` | Fluxo do bot exportado do TypeBot |
| `planilha-modelo.md` | Modelo de planilha usada como referência de dados |

## Como Usar

1. Importe o arquivo `typebot-vista-pitanga.json` em uma instância do TypeBot.
2. Ajuste os dados de contato e regras conforme o condomínio.
3. Publique o bot no canal desejado (WhatsApp, site, etc.).

## Observações

Feito para atendimento automatizado de moradores/visitantes do condomínio.
